# Litepad

Litepad is a lightweight text editor built using Python. It provides a simple and intuitive interface for editing text, offering basic functionality that can be extended further. This project also includes a pre-built executable file (`Litepad.exe`) for easy installation and usage.

## Features

- Lightweight and fast
- Simple text editing interface
- No installation required—just run the executable
- Cross-platform support (Python version)

## Getting Started

### Prerequisites

To run Litepad from the source code, you need to have the following installed:

- [Python 3.x](https://www.python.org/downloads/)

For users who prefer to use the pre-built executable (`Litepad.exe`), there are no prerequisites. Just download and run the file.

### Installation

#### From Source

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/litepad.git
    ```

2. Navigate into the project directory:
    ```bash
    cd litepad
    ```

3. Run the application:
    ```bash
    python litepad.py
    ```

#### Using the Executable

1. Download the latest release of `Litepad.exe` from the [Releases](https://github.com/your-username/litepad/releases) page.
2. Run `Litepad.exe` by double-clicking on it.

That's it! The Litepad window will open, and you can start editing your text.

## How to Use

- Open files: Use the "File" menu to open an existing text file.
- Save files: After editing, save your work through the "File" menu by selecting "Save" or "Save As".
- Editing: You can edit text within the main window. Use standard text editing shortcuts such as `Ctrl+C` for copy and `Ctrl+V` for paste.
